# Nano-Banana Prompts Plugin

A curated catalog of 91 viral prompts and use cases for Google's Nano-Banana image generation and editing technology.

## Source

This plugin is based on the [Nano-Banana Viral Prompts and Use Cases](https://github.com/aidzinr01-design/Nano-Banana-Viral-Prompts-and-Use-Cases) repository, which collects stunning images and prompts generated by Nano-Banana in various task scenarios.

## Features

- Browse 91 curated prompt templates organized by category
- Search prompts by use case, technique, or keyword
- Get detailed input requirements and ready-to-use prompts
- Categories include: Visual Transformation, Character Design, Photo Editing, Creative Design, Spatial/Geographic, Fashion, Food, Education, Entertainment, and more

## Usage

- `/nano-banana-prompts [query]` - Search and browse Nano-Banana prompt templates

## Categories

| Category | Examples |
|----------|----------|
| Visual Transformation | Illustration to figure, manga conversion, style transfer |
| Character Design | Character sheets, pose control, expression control |
| Photo Editing | Auto enhancement, colorization, outpainting, restoration |
| Fashion & Beauty | Virtual try-on, hairstyle changes, makeup |
| Spatial & Geographic | Map to street view, isometric models, 3D renders |
| Creative Design | Product packaging, merchandise, jewelry, chess sets |
| Food & Cooking | Recipe from ingredients, food photography, calorie annotation |
| Entertainment | Comics, stickers, LEGO figures, action figures, game UI |
| Education & Science | Infographics, model annotations, math reasoning |
| AR & Annotation | Real-world AR info, red pen annotations, watermarks |
